# 三个正式插件实施记录

用户已确认 JSON 编辑器、网页快开、Todo 的功能范围并授权 workflow 执行。串行实施，共享 SDK 接口完成后再集成插件，不启动并行代理。

1. 宿主：按已声明权限开放文档分块读写、动态搜索条目、定时通知。文件由原生选择器授权；普通桥接仍为 1 MiB；插件数据隔离，通知可取消且点击能回到具体待办。
2. JSON：CodeMirror 编辑、搜索替换、折叠、无损格式化、错误定位、按需树视图、文件打开/另存、持久草稿。10 MiB 为编辑验收目标，50 MiB 检验大文件边界与取消；不经 Double 转换大整数。
3. 网页快开：网址 CRUD、名称/别名/分组/收藏、主搜索索引、搜索模板、导入导出。仅允许 HTTP(S)，查询参数编码，删除和停用同步撤下索引。
4. Todo：CRUD、备注/优先级、今天/即将到期/逾期/完成视图、单次/每日/每周提醒、通知点击定位。记录先持久化；通知拒绝或失败明确展示，修改/完成/删除取消旧提醒。
5. 审查后冻结源码，运行聚焦原生测试、插件逻辑检查和真实 WebView 验证；构建安装一次最终产物。创建三个独立源码仓库并登记集市，补齐开发与使用文档。

已有 Finder 配置和用户数据不迁移、不清理。客户端接入中央目录不是本次范围。新的能力在旧宿主不可用时必须提示升级，不静默降级。
