# 文本工具示例包

[English](README.md) · [中文 UI 开发文档](../../docs/plugin-ui.zh.md)

在扩展包中选择本地导入此文件夹，审阅页面、脚本和附带文件后完成导入。展开包，打开「文本工具」的**搜索**开关。按 `Control+Option+Space`，输入 `text hello` 后按回车：页面会收到参数 `hello`。

页面提供大写转换、剪贴板复制、草稿保存，以及一个有进度输出、可取消的五秒后端演示。返回搜索再进入后会恢复草稿；关闭窗口只隐藏当前会话。后端示例只输出示例请求，不用于处理密码或用户日志。不要在生产插件中默认输出请求全文。

包内第二个功能「查看调用上下文」是纯 UI，没有脚本。它同时提供 `context` 搜索入口和 `.txt` 文件右键入口，两个开关可分别开启。

点击包内「插件配置」可修改输出前缀。网页读取普通配置，密码由原生表单管理，后端通过环境变量读取。示例无外部依赖，不需要 Node 或 XlogDecoder App。

编辑源文件后，在通用设置开启开发模式，再点击包的「重新加载本地包…」审阅并应用。网页检查器可用于调试；「重新加载页面」只重开已安装副本，不复制源文件。
